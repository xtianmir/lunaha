# lunaha

A music player for your local library.

This is the official home for lunaha downloads and community discussions. Visit the [website](https://lunaha.com/) for features and downloads.

Get the latest installers and portable downloads from [Releases](https://github.com/xtianmir/lunaha/releases/latest).

The website is hosted separately at lunaha.com. This repository does not contain the player source code or website files.

Visit [Discussions](https://github.com/xtianmir/lunaha/discussions) to share ideas, ask for help, or talk with the community.

## Control it from an AI assistant

Turn on **Allow AI assistants to control the player** in Preferences > System, press **Copy setup for your assistant** and paste the text into your assistant. How it works: [lunaha.com/assistants](https://lunaha.com/assistants).
